# 📱 GlowUp App — Guia de Acesso pelo Celular

Este pacote já vem pré-configurado para abrir em **tela cheia nativa no celular** e com um **servidor de rede Wi-Fi automático** para você testar no seu smartphone sem precisar publicar na internet.

## 📁 Estrutura de Pastas

```text
GlowUp_App_Celular_Completo/
├── Iniciar_App_Celular.bat   (Clique duplo no Windows para iniciar e ver o link do celular!)
├── README.md                 (Este guia)
├── frontend/
│   └── index.html            (Aplicação Mobile SPA responsiva e adaptada para toque)
└── backend/
    ├── package.json          (Dependências Node.js)
    └── server.js             (Servidor Express configurado em 0.0.0.0 com detector de IP)
```

## 🚀 Como Acessar pelo Celular (3 Formas Fáceis)

### Opção 1: Pelo Wi-Fi da sua casa (Recomendado - 1 Clique no Windows)
1. Certifique-se de que o **computador e o celular estão no mesmo Wi-Fi**.
2. Dê dois cliques no arquivo **`Iniciar_App_Celular.bat`**.
3. Uma janela preta abrirá mostrando exatamente o endereço do seu celular, por exemplo:
   `📱 No Celular (mesmo Wi-Fi): http://192.168.1.15:5000`
4. Digite esse endereço no navegador do seu celular (Chrome ou Safari).

*(Se usar Mac/Linux, abra o terminal na pasta `backend`, rode `npm install` e depois `npm start`).*

### Opção 2: Enviar direto para o Celular (Sem precisar de PC ligado)
1. Pegue apenas o arquivo **`frontend/index.html`** desta pasta.
2. Envie para você mesmo pelo **WhatsApp Web**, **Telegram** ou **Google Drive**.
3. No celular, baixe o arquivo `index.html` e abra com o navegador **Chrome**. Ele funciona 100% offline com todas as funções!

### Opção 3: Instalar na Tela Inicial como App (PWA)
1. Após abrir o link no navegador do celular:
   - **No Android (Chrome):** Toque nos **3 pontinhos** no canto superior direito > **"Adicionar à tela inicial"**.
   - **No iPhone (Safari):** Toque no ícone de **Compartilhar** (quadrado com seta para cima) > **"Adicionar à Tela de Início"**.
