# GlowUp TCC — Projeto Completo (Flutter + Backend + Banco de Dados)

## Melhorias Visuais Aplicadas (v2)
- Design System centralizado em `flutter_app/lib/theme/app_theme.dart`
- Paleta editorial harmonizada (Off-White `#FAF7F5`, Rose `#BE185D`, Slate `#1E293B`)
- Tipografia combinada (`Playfair Display` para títulos + `Plus Jakarta Sans` para leitura)
- Cards com bordas sutis (`1px`), sombras suaves, barra de progresso na rotina e transições fluidas.

## Como executar
1. **Backend (`backend/`)**: `npm install` e `npm start`
2. **Flutter (`flutter_app/`)**: `flutter create .`, `flutter pub get` e `flutter run`
